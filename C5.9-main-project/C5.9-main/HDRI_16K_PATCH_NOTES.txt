16K HDRI PATCH
===============

Environment file:
frontend/assets/environment/kloofendal_48d_partly_cloudy_puresky_16k.hdr

Changes in frontend/js/scene.js:
- Added RGBELoader for the Poly Haven Radiance HDR file.
- The full 16K HDR is sampled by the visible camera-centred dome.
- Removed the artificial lower-hemisphere clamp and grey horizon blend.
- HDR data remains linear and is displayed through the existing ACES tone mapping.
- PMREM and custom-water reflections are generated once from a capped 4096 x 2048 half-float rotated copy to reduce GPU memory and startup cost.
- Removed the corrupt 2-byte kloofendal_overcast_puresky.webp file.

Note: the 16K HDR is approximately 262 MB and will substantially increase download time and GPU memory use compared with the previous WebP.
